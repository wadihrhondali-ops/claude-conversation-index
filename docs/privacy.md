# Privacy

## What the index contains

Every row is keyed by conversation `uuid` and carries: a title (real or
inferred), timestamps, a message count, a project name/uuid, provenance
columns (`source_line`, `content_source`, `project_source`,
`project_changed`), and a link (`https://claude.ai/chat/<uuid>`). None of
that requires reading message content — except the two excerpt columns
below.

## `--with-excerpts`

By **default**, `build_index` copies no excerpt of conversation content:
`summary_excerpt` and `first_message_excerpt` are empty in every row.

Pass `--with-excerpts` to fill them:

- `first_message_excerpt`: the first sentence of the first user message,
  truncated to 200 characters.
- `summary_excerpt`: the first sentence of the conversation's summary,
  truncated to 300 characters.

These **are** excerpts of your conversation content, even though short and
truncated. Treat the resulting index file with the same care you would
give the conversations themselves — in particular, never publish it, and
never commit it to a public (or even shared-private) repository.

## What never to commit to a public repository

- Any real index CSV/Markdown this tool produced (with or without
  `--with-excerpts`).
- Your real `mapping.csv`.
- Any real `conversations.json`, project export, or ZIP from Claude.ai.
- `light_metadata` or any other account-metadata export.
- Any delta or "previous index" file built from real data.

`.gitignore` in this repository excludes files named `*.real.csv` /
`*.real.json` as a reminder, but the actual guarantee is you: everything
versioned in this repository (`examples/`) is synthetic data generated by
`tools/make_fixture.py`, never real conversations.

## If you build an index of your own real conversations

Keep it local, or in a private, access-controlled location. If you need
to share it (e.g. with a tool you trust), consider doing so without
`--with-excerpts` first, and only add excerpts if you specifically need
them and understand what you are sharing.
